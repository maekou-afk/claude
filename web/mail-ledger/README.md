# メール台帳 — ブラウザだけで動く .msg 解析ツール

`pst-tool`（リポジトリ直下）は `readpst` のインストールが必要ですが、
会社PCで管理者権限がなく、インストールはおろか `pip install` やスクリプトの
実行そのものが禁止されている場合に使う代替ツールです。

`mail_ledger.html` を**単体のファイルとして**ブラウザで開くだけで動作します。
インストール・スクリプト実行・ネットワーク通信は一切不要です。

## 使い方

1. Outlookで個別メールを選択し、エクスプローラーへドラッグ＆ドロップして
   `.msg` ファイルとして書き出す（フォルダごとドラッグすればフォルダ構造も
   保持されます）。
2. `mail_ledger.html` をブラウザで開く（ダブルクリックでOK。インストール
   不要）。
3. 「.msgファイルを選択」または「フォルダを選択」で、書き出した `.msg` を
   読み込む。
4. フォルダ別件数・送信者/ドメイン集計・添付ファイル一覧・キーワード検索
   がその場で表示されます。「CSVを保存」で結果をエクスポートできます。

処理はすべてブラウザ内のJavaScriptで完結しており、読み込んだファイルの
内容が外部に送信されることはありません。

## 仕組み

- `.msg`（Outlookアイテムファイル）はOLE複合ファイル形式（CFBF）で、
  [`@kenjiuno/msgreader`](https://www.npmjs.com/package/@kenjiuno/msgreader)
  というピュアJavaScriptライブラリでパースしています。
- 本文がプレーンテキストで保存されていない場合は、圧縮RTF
  （`PidTagRtfCompressed`）を `@kenjiuno/decompressrtf` で展開し、
  `rtf2text.browser.js` の簡易RTF→プレーンテキスト変換でキーワード検索
  用のテキストを抽出しています。

## ソースからビルドする場合

配布用の `mail_ledger.html` は、`page_top.html`（UI/CSS）+ 上記ライブラリを
esbuildでバンドルしたもの + `rtf2text.browser.js` + `app.js`（アプリ本体）
を1ファイルに結合したものです。ライブラリを更新する場合などは以下で
再ビルドできます（このビルド作業だけはNode.js環境が必要です。ビルド済みの
`mail_ledger.html` を配る分には不要です）。

```bash
cd web/mail-ledger
npm install
npm run build
```

## 制限事項

- `.pst` 全体は読めません（PSTは.msgと異なりOLE複合ファイル形式ではなく、
  専用のノードデータベース形式のため）。個別に `.msg` としてエクスポート
  したメールが対象です。
- 送信者のメールアドレスがExchange形式（`/O=EXCHANGELABS/...`）の場合、
  SMTPアドレスが取得できないことがあります（表示名は取得できます）。
- RTF本文のプレーンテキスト変換は簡易実装のため、複雑な書式のメールでは
  本文抽出が不完全な場合があります。
